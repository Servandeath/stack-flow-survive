# stack-flow-survive

Складская система для внутренней логистики: веб-админка для распределения
товара по зонам хранения + Android-приложение для сборщика с построением
маршрута по ячейкам заказа. Интеграция с МойСклад (JSON API 1.2).

## Проблема
- Начальнику склада нужно быстро понять, в какую зону/ячейку положить новый
  товар с учётом его характеристик (габариты, вес, условия хранения) и
  текущей загрузки зон.
- Сборщику по заказу нужен не список ячеек, а понятный маршрут по складу —
  в каком порядке их обходить.

## Архитектура
Один бэкенд (Python/FastAPI), два клиента:
- **Веб-админка** (Jinja2 + HTMX) — для начальника склада.
- **Android** (Kotlin + Jetpack Compose) — для сборщика.

Остатки и занятость ячеек — всегда живые данные из МойСклад (не кешируются).
Схема склада (координаты ячеек) и условия зон хранения — своя модель данных,
которой в МойСклад нет.

## Стек
- Backend: Python 3.11+, FastAPI, SQLAlchemy, SQLite
- Web: Jinja2, HTMX
- Android: Kotlin, Jetpack Compose, Retrofit
- Интеграция: МойСклад JSON API 1.2

## Настройка окружения
1. Скопируйте `backend/.env.example` → `backend/.env`, заполните
   `MOYSKLAD_LOGIN`/`MOYSKLAD_PASSWORD` или `MOYSKLAD_TOKEN`.
2. Скопируйте `backend/data/warehouse_layout.example.json` →
   `backend/data/warehouse_layout.json`, заполните реальными кодами ячеек.
